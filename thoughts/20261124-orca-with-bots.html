01 / Separate the Jobs

A coding harness is not a coordinator.

A coding harness—Pi, Claude Code, or any single-session CLI—is a sharp tool inside one repository session. Point it at a directory with a bounded problem and it reads files, edits code, runs tests, and stops.

Shipping a change usually crosses more than one surface and outlasts one terminal session. Reshaping this site meant reading an older config repository, shaping a two-week pitch into Obsidian, spinning up an isolated git worktree, previewing typography changes live, watching pull-request checks, and cutting legacy code across six commits. Without a coordinator, you are the glue between every one of those surfaces.

03 / Three Tools, Three Jobs

Why Pi and Obsidian stay on the bench.

Adding a persistent coordinator did not replace Pi or Obsidian. It stopped forcing one tool to impersonate the other two. Each stays sharp because its boundary is narrow.

Orca Coordinator & worktrees
Job: Persistent bot home (SOUL.md, MEMORY.md, items, event watches) that dispatches disposable repo workers in isolated git worktrees.
Invariant: Never merges or publishes unasked; workers own PR checks until green, then release.
Pi Direct coding harness
Job: Fast, programmable in-terminal agent when you want your own hands directly on one hard module, tight loop, or three-word fix.
Invariant: Session-scoped on purpose—no background daemon ceremony when direct manipulation is faster.
Obsidian Durable working memory
Job: Plain local Markdown pitches, claims, and drafts that outlive every chat window, model swap, or agent harness.
Invariant: The file holds the shaped state, not the chat scrollback.
04 / Where It Still Bites

Three failure modes from the same morning.

Delegating coordination removes terminal babysitting, not judgment. Every cross-hatched box at the bottom of Figure 2 bit at least once during this build:

1. Default-template gravity. Left unguided, the worker's first pass shipped cold Tailwind blue-gray slate and later rendered boxed, multi-colored badges that clashed with an ink-on-paper page (7e4b6f2). Taste cannot be delegated. Showing inline mockups in chat and enforcing Gruvbox Dark Medium, Warm Paper, and monochrome currentColor glyphs (cd0ff58) fixed it in one pass—only because a human looked at the rendered page and said no.

2. The ghostwriting trap. When a coordinator already holds your project notes, letting it polish or expand your prose is effortless—and fatal. Automated prose reads like every other model output on the internet. The rule that kept the site honest was binary: agents build pipelines, diagrams, and previews; prose under your name stays yours.

3. Dispatch ceremony on tiny edits. Spawning or reopening a supervised worktree worker, running a full audit, and watching CI makes sense for a multi-file change. For fixing a typo in one local file, opening Pi directly in the directory still wins.

05 / Check Yourself

Which job are you hiring for?

Pick the primary surface you would reach for on each task below to test the boundary.

1. Turn a shaped pitch into a feature branch, run a local preview server, fix two audit warnings, and wake you only when PR checks pass.
2. Pair interactively for 25 minutes inside one tricky parser module where every test failure changes the next design choice.
3. Decide whether a feature is worth two weeks or two hours—and write the three sentences explaining why you believe an approach works.
